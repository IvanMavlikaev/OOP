# OOP Лабиринт

Учебный проект консольной игры-лабиринта, где игрок должен дойти из левого верхнего конца карты до правого нижнего, набрав как можно больше монет и потеряв как можно меньше HP.

Уровень 1:\
х - игрок \
решётка - препятствие \
$ - монета\
